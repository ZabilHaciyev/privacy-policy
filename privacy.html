Privacy Policy

This Privacy Policy describes how the Encode ERP Taxes Exporter Chrome extension ("the Extension"), developed by Encode Software (encode-soft.com), collects, uses, stores, and shares information when you use it.

1. Data Collection

The Extension accesses the following data solely within your active browser session:

  • Invoice records displayed on the Azerbaijan e-Taxes portal (new.e-taxes.gov.az), including invoice numbers, dates, amounts, VAT figures, and counterparty names.
  • Encode ERP login credentials (host URL, username, password) entered voluntarily by the user in the extension popup. These credentials are stored locally on the user's device only.

We do NOT collect: name, email address, IP address, location data, browsing history, device identifiers, or any other personal information.

2. How Data Is Used

The data accessed by the Extension is used exclusively for the following purposes:

  • To extract invoice records from the e-Taxes portal and display them in a results table within the Extension.
  • To generate a downloadable Excel (.xlsx) file saved directly to the user's local device.
  • To format and transmit invoice data to the user's own Encode ERP server, but only when the user explicitly chooses the "Export to ERP" option.
  • ERP login credentials are used solely to authenticate the user's request to their own Encode ERP server. They are never sent to Encode Software servers.

All data processing happens locally within the user's browser. No data is sent to Encode Software servers for any purpose.

3. Data Storage

The Extension stores the following data locally on the user's device:

  • ERP credentials (host URL, username, password): Stored in chrome.storage.local on the user's device only. Retained until the user clears them manually or uninstalls the Extension.
  • Temporary export data: Stored in chrome.storage.local on the user's device only. Overwritten each time a new export is performed. Automatically deleted when the Extension is uninstalled.
  • Downloaded Excel files: Saved to the user's local Downloads folder. Fully under the user's control.

No user data is stored on Encode Software servers, cloud services, or any external systems.

4. Data Sharing

We do not sell, trade, or share user data with any third parties, except as described below:

  • User's own Encode ERP server (encode-soft.com): Formatted invoice records are sent to the user's own Encode ERP instance only when the user explicitly selects the "Export to ERP" option. This data is sent directly to the user's own server, not to Encode Software.
  • Third-party analytics or advertising services: No data is shared. The Extension does not use any analytics, tracking, or advertising tools.
  • Any other third party: No data is shared with any other third party under any circumstances.

5. Permissions Used

The Extension requests only the minimum permissions necessary:

  • storage: To save ERP credentials and temporary export data locally on the user's device via chrome.storage.local.
  • downloads: To save the generated Excel (.xlsx) file to the user's local device.
  • Host permission: new.e-taxes.gov.az: To inject the export button and read invoice data from the Azerbaijan e-Taxes portal.
  • Host permission: encode-soft.com: To send formatted invoice data to the user's own Encode ERP instance when the user chooses that export option.

6. Third-Party Libraries

The Extension bundles the SheetJS (xlsx) open-source library locally to generate Excel files. This library operates entirely within the user's browser and makes no external network requests. No third-party analytics, tracking, or advertising SDKs are included in the Extension.

7. User Rights and Data Control

Users have full control over their data:

  • All locally stored extension data can be cleared at any time via chrome://extensions → Details → Clear data.
  • Uninstalling the Extension automatically removes all chrome.storage.local data.
  • Downloaded Excel files remain on the user's device and are fully under the user's control.
  • Because we do not collect or store any data on our servers, there is no remote profile to access, correct, or delete.

8. Children's Privacy

This Extension is intended for business use only and is not directed at children under the age of 13. We do not knowingly collect any personal data from children. If we become aware that a child under 13 has provided personal information, we will take steps to delete such information.

9. Changes to This Policy

We may update this Privacy Policy from time to time. If we make material changes, we will update the "Last updated" date at the top of this page. Continued use of the Extension after any changes constitutes your acceptance of the updated policy. We encourage users to review this policy periodically.
